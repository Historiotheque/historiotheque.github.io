# Historiotheque.github.io

The official website of the Historiotheque organization — the front door of the art operation, research, and living archive.

Published with GitHub Pages at https://historiotheque.github.io (custom domain `historiotheque.ca` to be configured later via a `CNAME` file and DNS).

## Structure

- `index.html` — Home
- `projects.html` — the organization's repositories
- `studio-logs.html` — the running record of the work
- `research.html` — research questions, methods, bibliography
- `publications.html` — releases, DOIs, ORCID
- `about.html` — the operator, in the first person
- `404.html` — custom not-found page
- `css/style.css` — the whole visual design in one file
- `images/` — site images (header: `the-historiotheque-building.jpg`)

## Working on the site

Edit the HTML/CSS files, commit, and push — GitHub Pages rebuilds the site automatically on every push. See `FILL-IN-GUIDE.md` for how site updates work.
